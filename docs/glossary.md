date: 2026-11-24

ZasDict（Windows 版・Android 版）の UI に表示する用語を定める。両版で同じ語を使う。全ソフト共通の用語は ZasDesignSystem の [implementation/glossary.md](https://github.com/Zaslon/ZasDesignSystem/blob/main/implementation/glossary.md) に従い、ここでは言い換えない。

アイコン欄は Material Symbols（Rounded）の名前を示す。空欄の用語にはアイコンを付けない。

## 辞書ファイル

| 用語 | 意味 | 使わない語 | アイコン |
|---|---|---|---|
| 開く | 辞書ファイルを選んで読み込む。 | | |
| 上書き保存 | 開いている辞書ファイルに書き込む。 | 保存（ファイル操作として単独で使わない） | `save` |
| 名前を付けて保存 | 書き込み先のファイルを選んで書き込む。 | 別名で保存 | |
| 辞書を新規作成 | 空の辞書を作る。 | 新規辞書 | |
| 〇〇から読み込む | クラウド（GitHub、Dropbox、Box）上の辞書を取得して読み込む。 | 再読込、取得 | |
| GitHubにコミット | 辞書と更新履歴を GitHub へ書き込む。 | | `cloud_upload` |
| 〇〇に保存 | 辞書と更新履歴を Dropbox / Box へ書き込む。 | アップロード | `cloud_upload` |

## 単語・例文

| 用語 | 意味 | 使わない語 | アイコン |
|---|---|---|---|
| 見出し語 | 単語の綴り。 | 語、単語名 | |
| 単語を追加 | 単語を新しく作る。 | 新規登録 | `add` |
| 例文を追加 | 例文を新しく作る。 | | `add` |
| 単語を編集 | 既存の単語を編集画面で開く。 | | `edit` |
| 単語を複製 | 既存の単語を元に、新しい単語を編集画面で開く。 | コピー | `content_copy` |
| 削除 | 単語・例文や、その中の項目（訳語、関連語等）を取り除く。 | 消去 | `delete` |
| 登録 | 編集中の単語・例文を辞書に反映する。ファイルへの書き込みは「上書き保存」。 | 保存、確定 | `check` |
| 関連語 | 単語に結び付けた別の単語。 | 関係（関連語そのものを指す場合）、対象語 | |
| 関係 | 関連語の種類（対義語等）。 | | |
| 照会 | API 等でオンラインの情報を取得する。例えば、ZpDIC Online から例文の訳と補足を取得する。 | | |

## 設定・ツール

| 用語 | 意味 | 使わない語 | アイコン |
|---|---|---|---|
| 設定 | ソフト全体の設定。 | 環境設定、オプション | |
| 辞書依存設定 | 辞書ファイルに書き込まれる設定（punctuations、ignoredPattern）。 | | |
| 更新履歴 | 単語の追加・変更・削除の記録。 | 変更履歴、changelog | |
| 書き出す | 更新履歴をファイルとして保存する。 | エクスポート | `download` |
| 連携 | 更新履歴 CSV を辞書と結び付け、保存のたびに追記させる。 | | |
| 変換 | 方言変換ツール。 | | |
| IPA → 綴り | IPA から綴りを得るツール。 | IPA（ツール名として単独で使わない） | |
| 凡例 | 品詞・関係の一覧。 | | |
